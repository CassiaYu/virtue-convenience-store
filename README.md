# 美德便利店

围绕“当中华传统美德遇上现代生活”的中文网页小游戏。

## 玩法

90 秒服务顾客，选对行动获得善意值与六种美德印章。顾客等待过久或行动不合适扣信誉。连击加分；集齐六枚印章奖励 300 分并恢复所有等待顾客的耐心。另有无倒计时、不扣信誉的 12 单练习模式。

电脑：点击或用 1/2/3 选顾客，用 Q/W/E/A/S/D 选择对应行动，空格暂停。手机：直接触屏操作。切换到其他页面会自动暂停。

## 文件

`dist` 是完整静态网站，可直接双击 `dist/index.html` 离线游玩，或部署至静态网站服务。无需安装依赖。仅本机挑战最佳分使用 localStorage，不上传玩家数据。

`tests/engine.cjs` 可用 Node.js 运行，验证游戏状态机。

## 创作说明

仁爱、诚信、礼让、节俭、敬老、责任六种价值，分别落到现代校园互助、移动支付与失物归还、有序排队、按需消费、长者数字生活、节能环保中。成绩代表游戏表现，不代表品德评价。

场景插画由 AI 辅助生成，所有网页交互为实际可运行的代码。插画原始提示：当代中国校园附近便利店，正面剖视场景，学生店员、年轻顾客及长者，货架、微波炉、饮水处、失物招领箱；朱红、深青、暖金色，手绘独立游戏风格，无界面文字。图像通过内置 imagegen 生成。
